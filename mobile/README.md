# Fio do Bigode Mobile

Primeira base nativa do aplicativo em React Native + Expo.

## Estado atual

- Login demonstrativo
- Home
- Negociações
- Novo acordo
- Detalhe do acordo
- Carteira / Bigode Bank (BaaS fictício)
- Publicidade demonstrativa
- Perfil e reputação
- Navegação inferior
- Dados mockados, ainda sem backend

## Executar

```bash
cd mobile
npm install
npx expo start
```

A base está propositalmente sem backend nesta etapa. O próximo ciclo será persistência local, fluxo completo de acordo e preparação para API.
